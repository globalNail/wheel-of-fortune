# 🧩 TASK: GameFeedbackSystem

## 🎯 Objective
Show clear feedback for player actions using toast or popup

---

## 🎯 Events

SPIN:
- “Bạn quay được 500 điểm”
- “Phá sản!”
- “Mất lượt!”

GUESS:
- đúng: “Chính xác! +1000 điểm”
- sai: “Sai rồi!”

BUY VOWEL:
- đúng: “Có chữ A”
- sai: “Không có nguyên âm này”

SOLVE:
- đúng: 🎉 “Chính xác! Bạn thắng!”
- sai: “Sai rồi! Mất lượt”

---

## 🧠 Implementation

- use toast library OR custom component
- global event listener

---

## ⚠️ Rule

- feedback must be visible to ALL players
